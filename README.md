# EraseMe

Ferramenta de proteção de privacidade e remoção de conteúdo não consensual.

Localiza exposições indevidas, preserva provas, gera denúncias e acompanha o status de cada solicitação.

## O que o EraseMe faz

- Ajuda a identificar páginas, perfis, anúncios e mídias com conteúdo não consensual
- Orienta pesquisa reversa de imagens
- Analisa tecnicamente links (domínio, host, CDN, canais de denúncia)
- Gera textos prontos de denúncia para Google, redes sociais, sites e provedores
- Orienta a preservação de provas antes de qualquer pedido
- Diferencia claramente:
  - remoção da página original
  - desindexação nos buscadores
  - remoção de cópias
- Oferece modo profissional para advogados, delegacias e organizações de apoio

## Público-alvo

- Vítimas de divulgação de imagens íntimas
- Pessoas com perfis falsos, golpes ou anúncios fraudulentos
- Exposição de telefone, endereço ou dados pessoais
- Uso indevido de fotografias
- Casos envolvendo menores
- Profissionais de apoio (advogados, delegacias, gabinetes e organizações)

## Como rodar localmente

1. `npm install`
2. Configure a chave do Gemini em `.env.local` (`API_KEY=sua_chave`)
3. `npm run dev`

## Aviso importante

Esta ferramenta fornece orientações gerais e modelos de texto.  
**Não constitui aconselhamento jurídico.**  
Em situações de risco imediato, procure a polícia (190) ou delegacia especializada.
